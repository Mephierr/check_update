# Скрипт проверки обновлений пакетов

Этот скрипт помогает проверить и при необходимости обновить установленные пакеты на вашей системе. Он поддерживает несколько популярных дистрибутивов Linux и macOS (через Homebrew).

## Описание

Скрипт:
- Автоматически определяет используемый менеджер пакетов.
- Проверяет наличие обновлений для операционной системы.
- Проверяет версии указанных пакетов и сравнивает их с последними, доступными в интернете.
- Может автоматически устанавливать обновления (опционально).
- Поддерживает: **apt**, **dnf**, **yum**, **pacman**, **zypper** и **brew**.

**Поддерживаемые пакеты для проверки версий:**
- Nginx
- OpenSSL
- Docker (`docker`, `docker-ce`)
- Python (`python`, `python3`)
- PostgreSQL
- Node.js (`node`, `nodejs`)

## Установка зависимостей

Если включена опция `INSTALL_DEPS=true`, скрипт установит необходимые зависимости:
- `curl`
- `grep`
- `awk`
- `jq` *(для работы с JSON)*

## Файл `packages.txt`

Вы можете указать список интересующих вас пакетов в файле `packages.txt`. Каждый пакет должен быть указан на новой строке. Строки, начинающиеся с `#`, считаются комментариями и игнорируются.

Пример `packages.txt`:
nginx
openssl
python3
nodejs
docker
postgresql

## Настройки

Настройки задаются в начале скрипта:

```bash
AUTO_UPDATE=false  # true - автообновление, false - только вывод информации
INSTALL_DEPS=true  # установить недостающие зависимости
PACKAGES_FILE="packages.txt"  # имя файла со списком пакетов
```

## Цветовая индикация

- 🟢 `[✓]` — система или пакет актуальны  
- 🔴 `[!]` — доступны обновления  
- 🟡 `[?]` — информация не найдена или пакет не установлен  
- 🔵 `[ИНФО]` — информационные сообщения  
- ❗ `[ОШИБКА]` — критическая ошибка, приводящая к завершению скрипта  

## Использование

1. Сделайте скрипт исполняемым:
   ```bash
   chmod +x update_checker.sh
   ```

2. Запустите его:
   ```bash
   ./update_checker.sh
   ```

3. При необходимости отредактируйте `packages.txt` и настройки в начале скрипта.

## Примечания

- Для некоторых команд требуются права суперпользователя (sudo). Убедитесь, что у вас есть доступ.
- Скрипт использует внешние ресурсы (официальные сайты) для получения последних версий пакетов.
- Если вы хотите использовать автоматическое обновление, установите `AUTO_UPDATE=true`.
